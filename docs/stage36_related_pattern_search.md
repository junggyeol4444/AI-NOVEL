# Stage 36 — 관련 통계 패턴 검색 (완전 오프라인)

## 목표 및 범위

35단계에서 **사용자가 저장한** 참고 통계 요소를 기준으로, 기존 로컬 SQLite에 저장된 **다른 장르의 현재 유효한 패턴**을 찾아 통계 근접도순으로 반환한다. 이 기능은 원문 검색, 키워드 검색, pgvector, 의미 기반 AI 분석, 작가 문체 복제, 집필 지시 생성과 무관하다.

## 검색 절차

1. 사용자 장르(`fantasy` 등)와 가중치(`equal` 또는 `characters`)를 지정한다.
2. `ElementSelectionStore.get()`이 저장된 1~6개 통계 항목을 재검증한다. 선택을 저장하지 않았거나 장르의 작품 구성이 바뀌면 검색을 거부한다.
3. `GenrePatternStore.list_patterns()`로 **동일 가중치**로 저장된 다른 장르 패턴만 열거한다.
4. `preview_strengths()`로 각 후보를 재계산한다. 장르 작품 구성이 바뀌었거나 원문 없는 프로필이 누락된 패턴은 제외한다. 활성 참고작 수가 2개 미만이거나 한 작품의 실효 비중이 60%를 초과하는 패턴도 제외한다.
5. 각 선택 항목만 비교해 단위 없는 거리 `d = min(1, |source - candidate| / max(scale, |source|, |candidate|))`를 계산한다. 고정 `scale`은 비율 1, 감정 균형 2, 평균 문장 길이 20자, 사건 단서 밀도 10/1000자로 설정했다. 이들은 **수학적 정규화 상수**이며 창작 목표가 아니다.
6. `100 × (1 - 평균 거리)`를 소수점 2자리로 표기한다. 결과는 근접도 내림차순, 동률이면 장르 코드순으로 정렬한다. 원본 장르는 제외한다.

검색 한도는 1~11개이며, 12개 고정 장르 분류를 넘어서 외부 콘텐츠를 검색하지 않는다. 선택 항목에 따라 순위가 달라질 수 있다. 수치 근접도가 높다고 창작 적합성, 작품 품질, 서사 의미나 표절 위험이 낮다는 의미는 **아니다**.

## 명령줄 실행 (서버 불필요)

프로젝트 루트에서 (Python 3.12 환경 권장):

```bash
PYTHONPATH=src python -m ai_novel_factory.references.profile_cli \
  --database ./references.sqlite3 pattern-related fantasy --weighting equal --limit 5 --min-similarity 65
```

선행 준비: `genre-assign` → `genre-build`(비교할 장르 각각) → 기준 장르 `elements-save`. 다른 장르의 `elements-save`는 요구하지 않는다. 참고작 강도 기본값은 50이며, 최소 2작품/단일 60% 규칙을 적용한다.

PySide6 참고작 화면의 **선택 요소로 관련 패턴 검색** 버튼도 같은 기능을 직접 호출한다. 버튼 클릭 시에만 검색한다. 저장 DB는 기존 `ReferenceCatalog`의 SQLite 파일이다.

## 파일·데이터 보호

- 분석 대상은 기존 원문 없는 Reference Profile 숫자 데이터와 사용자 선택의 고정 통계 코드뿐이다.
- 반환 레코드에 장르 코드, 작품 수, 통계 근접도, 항목별 수치 차이만 포함한다. 원본 소설 원문·인물명·고유 문장·파일 경로·실제 제목은 반환하지 않는다.
- 검색 기록을 SQLite에 따로 남기거나 파일에 쓰지 않는다.
- GitHub API, 외부 서버, 네트워크, API 키, 로컬 AI 모델 사용이 없다.
- 틀린 입력·손상된 결과는 고정 메시지로 거부해 민감한 입력 내용을 오류에 되풀이하지 않는다.
