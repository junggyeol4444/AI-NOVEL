# AI Novel Factory: 대화 전용 개발 설정 (2026-10-12)

- 사용자가 명시적으로 재승인하기 전까지 GitHub 저장소 조회·업로드·커밋·PR·병합·Actions를 사용하지 않습니다.
- ChatGPT의 기존 AI Novel Factory 시간별 예약은 비활성화되어 있으며, 사용자가 `예약`이라고 말하기 전에는 켜지 않습니다.
- 이 ZIP에는 `.git/`, `.github/`, `.gitattributes`를 포함하지 않습니다. `.gitignore`는 외부 연동을 만드는 설정이 아니며, 비밀키·원고가 실수로 포함되지 않도록 하는 기존 보안 규칙과 회귀 테스트 때문에 보존합니다.
- 앞으로 `계속` 요청 시 이 대화에서 누적 소스를 개발·테스트하여 ZIP으로 전달합니다.
- 기존 원격 저장소/계정에 이미 저장된 과거 커밋과 워크플로는 이 작업에서 변경하거나 삭제하지 않았습니다. 원격 삭제에는 다시 GitHub 연결이 필요하며, 사용자 요청에 따라 이를 사용하지 않습니다.
- GitHub 계정의 앱 연결 해제는 전역 설정이므로 이 프로젝트 코드와 별개입니다.
- AI는 로컬 실행 중심으로 개발하며 외부 유료 API 호출을 기본 동작으로 사용하지 않습니다.
