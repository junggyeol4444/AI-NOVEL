# 56단계 — pgvector 기반 과거 장면 의미 검색

- 로드맵: 56단계, ANF-REQ-040. 출처 회차/장면 번호 표시.
- `search_scenes`: 오프라인에서 **외부에서 전달받은 벡터**를 정확 코사인 유사도로 검색하는 기준 구현. 작품 격리, 미래 회차 제외, 중복·벡터 오류 검사.
- `pgvector_search`: **호출자가 전달하는** PostgreSQL 연결에 파라미터 바인딩 SQL을 실행하는 어댑터. 연결을 열거나 네트워크에 접속하지 않음.
- `PGVECTOR_SCHEMA`: 3차원 벡터를 위한 예시 스키마. 실제 임베딩 모델 차원에 맞춰 마이그레이션 필요.
- **미구현/미검증**: 로컬 PostgreSQL/pgvector 실제 인스턴스 통합 테스트, 로컬 임베딩 모델, 자동 DB 저장/연결, Windows EXE. 따라서 실제 의미 검색 품질은 검증되지 않음.
- Novel Bible 우선, 참고작 원문 비복제, 출판 전 사용자 승인 정책 변경 없음.
