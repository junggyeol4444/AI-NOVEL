# 98단계 — 설치·설정·외부서비스 연결 안내 (오프라인 문서 및 진단)

## 공식 원본 및 인수 조건

- 사용자 제공 공식 100단계 로드맵 **98: 설치·설정·외부서비스 연결 안내**.
- 기존 `docs/requirements.md` **ANF-REQ-070**: EXE 실행에 필요한 외부 구성요소 명시 및 **필수·선택·유료** 구분.
- 원본 기획안 TXT (`붙여넣은 텍스트(1)(7)(1).txt`)는 현재 접근 가능한 대화 파일에서 확인되지 않았다. 공식 로드맵 요약과 누적 ZIP 내부 요구사항을 사용했으며, 없는 ANF-REQ를 추가하지 않는다.
- 이번 단계는 **설치 안내 및 읽기 전용 자체 점검**만 한다. 사용자 PC에 설치, 서비스 연결, 계정 로그인, 결제, 구성 변경을 실행하지 않는다.

## 배포 상황과 설치 경로

**현재 배포 상태:** Windows `.exe`가 실제로 생성·실행되었다는 증거가 없다. 사용자에게 실행 가능한 완성 EXE를 제공한 상태가 아니다. 97단계 Windows 인수 **미충족**. 다음 가이드는 정식 Windows EXE 빌드가 가능해진 후에만 적용한다.

1. **완성 EXE 사용 경로(미검증):** Windows x64 환경에서 배포자가 Windows 상에서 직접 빌드하고 테스트한 `AI_Novel_Factory.exe`와 검증된 SHA-256을 확인한다. PyInstaller one-file 배포라면 Python 설치는 일반 사용자에게 필요하지 않도록 묶이는 것이 목표이나 **검증되지 않았다**.
2. **소스 개발/검증 경로(Windows x64):** 로컬 Python **3.12.x** 환경과, 사용자가 별도로 합법적으로 확보한 오프라인 설치 패키지가 준비된 경우에만 `pyproject.toml`의 해당 extras에 맞춰 의존성을 설치할 수 있다. **여기서는 설치 명령을 실행하지 않는다.** Python 3.13으로의 호환성은 보증하지 않는다.
3. **빌드 경로(Windows 개발자 전용):** 이미 설치된 `PyInstaller`와 `PySide6`를 사용하는 Windows/Python 3.12에서 `python scripts/build_windows_exe.py --preflight-only` 로 진단한다. 준비가 된 경우에 한해 `python scripts/build_windows_exe.py --report build/stage97-result.json`를 로컬에서 명시적으로 실행할 수 있다. 결과의 `windows_runtime_verified=true`가 없으면 성공이라고 선언할 수 없다. 실제 화면 실행·종료/오프라인 검증은 99단계 과제다.
4. **개인 소설/참고작 파일:** 압축 소스/배포 패키지에 넣지 않는다. 사용자가 허락한 로컬 파일만 프로그램에서 선택하도록 한다. 임의 폴더의 원고 자동 수집 금지.

## 안전한 로컬 설정

- 개발용 `.env.example`은 자리표시 템플릿일 뿐 실계정 키를 입력하거나 자동 적용하는 파일이 아니다.
- `ANF_AI_PROVIDER=disabled` 또는 사용자 준비한 `local`만 허용. 로컬 AI 모델이 실제 동작한다는 의미가 아니다.
- `ANF_API_HOST=127.0.0.1` 기본; `localhost`, `::1`만 허용. 외부 바인딩 `0.0.0.0` 및 원격 AI 공급자 차단.
- `ANF_DATABASE_URL`, `ANF_REDIS_URL`은 현재 오프라인 모드에서 **비워야 한다**. 원격 서버 자격증명/토큰을 등록하지 않는다.
- 로컬 앱은 비밀키를 요구하지 않는다. 실제 토큰, 참고작 원문, 원고, 프롬프트를 진단 로그·배포 ZIP에 기록하지 않는다.
- 사용자가 설정을 변경해야 할 경우 먼저 데이터 백업을 진행하되 원고/개인 데이터 파일을 이 개발 대화에 올리거나 제3자에게 전송하도록 요구하지 않는다.

## 네트워크 없는 진단 사용법

```powershell
# 사용자 PC가 아니라 검증하려는 로컬 환경에서 사용자가 직접 실행
python scripts/stage98_offline_setup.py
# 보고서 파일을 원할 때, 기존 파일을 덮어쓰지 않음
python scripts/stage98_offline_setup.py --report setup-report.json
```

- 표준 출력과 JSON에는 서버 주소, API 키, 원고 제목, 로컬 사용자 경로 등 민감한 원본 값을 기록하지 않는다.
- 기본 설정만 자체 검사하며 실제 사용자 설정 파일이나 환경 변수 내용은 자동 탐색하지 않는다.
- `windows_build_preflight_possible=true`는 **빌드 전제조건 충족 가능성**일 뿐 빌드/GUI 실행/출판 성공이 아니다.
- `user_pc_inspected=false`는 이 대화 실행 환경이 사용자 PC가 아님을 명시한다. 보고서의 속성은 로컬에서 그 도구를 실행한 인터프리터 관찰 결과다.
- `--report`는 **기존 파일을 덮어쓰지 않고** 부모 폴더를 자동 생성하지 않으며, 외부 서비스에 전송하지 않는다.

## 외부 서비스 연결 안내 / 정책상 현 상태

- **GitHub·원격 저장소·클라우드 AI API·외부 출판 서비스**: 연결 금지. URL/키 발급 또는 시험 업로드 절차를 자동으로 실행하지 않는다.
- 외부 Publisher Adapter(95단계)는 오프라인 모의 인터페이스만 있다. 공식 제공자 문서·테스트 서버·계정 인증·테스트 업로드 **미검증**.
- 플랫폼별 적합성(96단계)은 사용자가 선언한 형식 조건과 로컬 자료만 검사하므로 공식 업로드 가능 여부는 `UNKNOWN`이다.
- 사용자 검수/승인(89단계)은 로컬 확인 기록이며 실제 사용자 신원 인증은 미검증이다.
- 사용자가 추후 **명시적으로** 로컬/외부 연결 방침을 바꾸더라도 공식 규격·보안·개인정보·비용과 출판 승인 제어를 다시 설계·검증하기 전에는 네트워크 출판을 활성화하지 않는다.

## 검증되지 않은 조건 및 다음 순서

- 95: 공식 API 업로드 미검증 / 인수 미충족.
- 96: 공식 형식/업로드 가능성 미검증 / 인수 미충족.
- 97: Windows EXE 실빌드/실행 미검증 / `ANF-REQ-001` 인수 미충족.
- 98: `ANF-REQ-070`의 **설치·설정 필수·선택·유료 요소 안내**와 로컬 무설치 검사 기능을 제공한다. 설치 안내가 제품 전체 작동/호환성을 보증하지는 않는다.
- 99: 사용자 Windows 실기기 GUI 실행·종합 회귀 테스트 **미착수**.
- 100: 최종 릴리스·사용자 인수시험 기준 **미착수**.

실제 검증한 범위만 `docs/stage98_test_results.json`, `docs/stage98_verification_log.txt`에 기록한다. 사용자 승인 없는 원고 확정·출판·업로드 금지.
