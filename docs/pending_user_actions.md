# PC를 켠 뒤 사용자 확인이 필요한 사항 (5단계 기록)

지금 당장 조치할 사항은 없습니다. 사용자가 다시 말을 걸었을 때만 설명하고 승인 여부를 묻습니다.

1. Windows 버전, 64비트 여부 및 개발/실행 PC 사양 확인.
2. Python 3.12와 패키지 관리자 uv 설치 허용 여부.
3. Git 사용 및 원격 저장소/클라우드 CI 연결 허용 여부.
4. 로컬/원격 API·PostgreSQL·Redis·worker 실행 위치 결정.
5. 유료 AI 제공자, 키, 비용 한도 결정 (61~62단계에서 상세화).

승인 전에는 설치, 로그인, 결제, 외부 저장소 업로드를 하지 않습니다.

## 6단계 추가 보류 항목
- 실제 AI API 키와 제공자 선택은 61~62단계에 사용자 승인 후 수행.
- DB/Redis 연결 문자열과 호스팅 위치는 사용자 확인 전 비워 둠.
- 운영용 Windows 자격 증명 저장소 채택 및 접근 권한 설계는 사용자 승인 후 결정.

## 9단계 추가 보류 항목
- 사용자 PC에서 FastAPI 및 uvicorn, PySide6 설치 및 실행 승인 필요.
- 로컬 API 실행 포트 변경 여부는 사용자 PC를 켠 뒤 결정.
- 외부 네트워크 공개 및 원격 접속은 이번 단계에서 지원하지 않음.

## 10단계 추가 보류 항목
- 사용자 PC에서 Python 3.12 기준으로 전체 스모크 테스트 재실행 여부 확인.
- FastAPI/uvicorn 임시 로컬 HTTP 테스트 및 PySide6 오프스크린 GUI 테스트 실행 승인.
- 실제 Windows GUI 표시 및 EXE 실행 검증은 해당 개발 단계까지 보류.

## 11단계 추가 보류 항목
- 사용자 Windows PC에서 PySide6 GUI를 실제로 띄워 파일 선택·취소·초기화 동작 확인.
- 실제 참고소설 원문 제공·분석은 이번 단계에서 요구하지 않음; 원문 읽기/검증은 후속 단계에서 명시적 선택 후 수행.

## 16단계 추가 보류 항목
- Windows PC에 PDF 파서용 `pypdf>=5,<7` 설치와 Python 3.12 테스트는 사용자가 PC를 켜고 승인한 뒤 진행.
- 실제 참고용 PDF의 테스트 제공 여부는 사용자가 결정. 저작권 이용 권한 없는 문서 분석/전송은 요청하지 않음.
- 이미지 기반 PDF의 OCR 기능은 **16단계 범위에서 제외**; 필요 시 사용자와 기능·비용·개인정보 처리를 먼저 결정.
