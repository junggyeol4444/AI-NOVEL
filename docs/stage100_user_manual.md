# AI Novel Factory — 사용자 설명서 (100단계, 소스/오프라인 시험판)

> **배포 경고:** 이 파일은 정식 출판 프로그램 설치 설명서가 아니다. 2026-10-14 기준 Windows EXE 실빌드·GUI 실실행·공식 출판 API 실검증이 없으며 **정식 출시 승인 불가** 상태다. 사용자는 EXE가 제공되었다고 오인하면 안 된다.

## 1. 현재 가능한 일과 검증 범위

- 로컬 Python 소스의 데이터베이스·기획·모의 집필·참고 분석·검사·기억 갱신 및 내보내기 구성 요소는 단계별 테스트 기록으로 검증되었다. 자연어 의미 판단과 실제 장편소설 자동 집필 품질은 보증되지 않는다.
- 91단계 로컬 표지 생성은 절차적 도형/텍스트 합성이다. AI 그림 생성, 디자인 독창성 법적 확인 기능은 아니다.
- 92단계 로컬 메타데이터, 93단계 EPUB3, 94단계 회차별 TXT 내보내기는 **출판 준비 파일**을 만든다. EPUBCheck·모든 리더 호환성 및 플랫폼 적합성 실검증은 별도다.
- 95~96단계의 출판 Adapter와 플랫폼 형식 확인은 **오프라인 제한 기능**이며 공식 API 접속·업로드 결과는 없다.
- 97~99단계의 Windows 빌드/실행 검증 도구는 준비됐으나 실제 Windows EXE 성공 증거가 없다.

## 2. 실행 전에 확인할 사항

1. 실제로 Windows x64 컴퓨터가 있고, 사용자 본인이 로컬 설치를 승인했는지 확인한다. 이 작업에선 사용자 PC에 접근하거나 설치하지 않았다.
2. 배포가 가능해지면 별도로 Windows에서 빌드·실행·GUI 표시와 전체 회귀를 검사한 EXE, 해당 SHA-256, 사용 설명서 및 검증 기록을 비교한다. **현재 그런 EXE가 제공되지 않는다.**
3. 개발용 소스 확인은 `pyproject.toml`의 Python **3.12.x** 요구와 선택 의존성을 따른다. 외부 패키지를 자동 다운로드하지 않는다. 준비된 Python/의존성이 없다면 설치했다고 가정하지 않는다.
4. 소스 사전검사: `python scripts/build_windows_exe.py --preflight-only` (설치·빌드하지 않음). Windows 수동 검사 절차는 `docs/stage99_windows_integrated_regression.md`를 따른다.
5. 릴리스 준비 검사(읽기 전용): `python scripts/stage100_release_audit.py --report local_release_audit.json` (기존 파일 덮어쓰기 금지). 결과의 `release_status=BLOCKED`이면 출시·설치 배포 불가. **검사가 PASS여도 자동 승인이 아니다.**

## 3. 로컬 사용 흐름 (구현 계약 기준, GUI 실사용 미검증)

1. 작품 장르·소재·목표 길이·분위기·주요 설정을 입력하고, 필요한 경우 **사용 권한이 있는** 참고소설 파일을 직접 선택한다.
2. 참고파일 TXT/MD/EPUB/DOCX/PDF의 통계·구조를 분석하고 Reference Profile을 저장한다. 원문이나 고유명사·인물을 복제 목적으로 입력하지 않는다.
3. Novel Bible을 먼저 검토·저장한다. 참고 패턴보다 Novel Bible이 우선한다. Story Arc, 회차, Scene 계획을 검토한다.
4. 로컬 Mock Writer는 통합 테스트에 쓰이며 실제 자연어 장편 집필 성공을 보장하지 않는다. 모의 초고와 실제 사용자 원고를 혼동하지 않는다.
5. 회차별 연속성·논리·문체·반복·참고 유사성·독자 참고 지표를 확인한다. 자동 검사가 불확실하면 사람의 검토가 필요하다.
6. 결함이 있는 Scene만 수정하고 **수정된 원고로 재검사**한 뒤, 사람의 승인에 따라 기억 변경 후보를 검토한다. 승인 없이 원고 최종 확정이나 출판을 하지 않는다.
7. 표지/메타데이터/EPUB3/회차별 TXT는 로컬 검토용으로만 내보낸다. 플랫폼 업로드 연결은 현재 금지돼 있다.

## 4. 원고·참고작·보안

- 원고·참고작·프롬프트·API 키는 무단 업로드 금지. 임의 경로의 파일을 자동 수집하지 않으며 자료 제공은 사용자의 자발적 선택 사항이다.
- `.env.example`은 설정 예시이며 실제 비밀키 입력 용도로 배포하지 않는다. 로그나 이슈에 원문·비밀번호를 붙이지 않는다.
- Novel Bible이 Reference Profile보다 우선한다. 유사성 검사는 완전한 저작권 판정을 대신할 수 없다.
- 외부 서버·GitHub·클라우드 AI·원격 플랫폼 접속은 현재 금지이며, 프로그램에서 유료 구매·계정 연결·외부 게시를 자동 수행하지 않는다.
- 로컬 데이터의 백업·삭제·보관 위치와 파일 접근 권한은 사용자가 직접 정해야 한다. 민감한 원고가 포함된 DB/JSON을 무분별하게 공유하지 않는다.

## 5. 문제 해결과 알려진 제약

| 상황 | 현재 대응 |
|---|---|
| Windows EXE가 없음 | 단계 97 Windows 실빌드/99 실제 실행 미검증. 소스 ZIP을 EXE로 착각하지 않음 |
| PySide6·PyInstaller 없음 | 사전검사가 차단을 보고; 패키지를 자동 설치하지 않음 |
| Python 3.13 | 프로젝트는 Python 3.12가 목표. Linux 3.13 회귀 결과만 존재 |
| GUI가 안 보임 | Qt offscreen/모의 테스트와 실제 물리적 Windows 화면은 다름 |
| 플랫폼 파일을 업로드할 수 없음 | 95~96단계 공식 규격·실환경 검증 없으므로 외부 게시 기능 차단 |
| EPUB이 일부 리더에서 열리지 않음 | 내장 구조 검사만 완료. EPUBCheck와 리더 실검증 필요 |
| AI 집필 결과가 부자연스러움 | Mock Writer 통합 테스트는 실제 로컬 LLM 자연어 품질 시험이 아님 |
| PDF 스캔본 | 텍스트 PDF 중심으로 구현되었고 OCR은 보장하지 않음 |
| SQLite 관련 경고 | 기존 테스트의 연결·자원 관리 경고가 남을 수 있음; 결과와 분리해 기록 |

## 6. 사용자 승인 및 최종 제품 판정

- 로컬 원고 확정 승인, 외부 게시 승인, 소프트웨어 최종 릴리스 승인 등은 **서로 다른 행위**다. 어느 것도 자동으로 대신하지 않는다.
- 배포 전 `docs/stage100_release_and_acceptance.md`의 판정 기준을 모두 충족하고, 실제 Windows 화면과 EXE 종료, 보안/회귀, 공식 게시 플랫폼의 허용된 테스트 실증을 사람이 확인해야 한다.
- 본 소스 ZIP은 **배포 보류 상태의 개발 산출물**이며 완성된 `AI Novel Factory.exe`가 아니다.
