# AI Novel Factory — 요구사항 명세서 (1/100 단계)

> 상태: 요구사항 문서 작성 완료 / 기능 구현 전 / Windows 검증 전

## 1. 범위와 우선 규칙

- 목표 제품: Windows EXE 형태의 장편소설 자동 기획·집필·검수·출판 관리 도구.
- 사용자가 장르·소재·목표 회차·분량·분위기·참고소설을 입력하면 기획→회차 집필→검수→완결→출판 준비 흐름을 지원한다.
- 참고소설은 허용된 자료만 입력받고 구조적·통계적 패턴을 분석한다. 원문 문장·고유 설정의 직접 복제를 금지한다.
- Novel Bible이 참고 작품 패턴보다 우선한다. 유사성 검사를 집필 확정 과정에 포함한다.
- 실제 외부 출판, 유료 API 이용, 계정 연결, 로컬 PC 설치는 사용자의 명시적 승인 전 수행하지 않는다.
- 이번 단계는 요구사항만 정의한다. EXE/백엔드/DB 구현은 후속 단계에서 진행한다.
